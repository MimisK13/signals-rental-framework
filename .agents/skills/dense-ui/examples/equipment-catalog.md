# Dense Equipment Catalog

Context: rental operators search equipment across stock locations. Goal: compare availability and open the right record quickly. PRIMARY: equipment name/ID, type, availability, location. SECONDARY: serial, next booking, condition. TERTIARY: supplier/financial metadata.

Use a compact table with search, status/location filters, saved view, sortable columns, sticky header, and trailing row menu. Keyboard: `/` focuses search, arrows move results only if native semantics are preserved, Enter opens, Space selects. Mobile keeps identity/status/location and moves metadata into a detail view. Use illustrative records such as Midas M32, L-Acoustics K2, Shure ULX-D, and XLR 5m; these examples do not imply endorsement.

Mistakes: card-per-item, equal-weight metadata, hidden availability, or ten visible row buttons.
