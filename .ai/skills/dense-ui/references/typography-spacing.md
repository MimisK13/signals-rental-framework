# Typography and spacing

Use a readable system font with stable line-height. Normative defaults are 14px UI/table text at 20px line-height, 12px labels/metadata at 16px line-height, 20px page titles at 28px line-height, and 14px numeric data with tabular numerals. Use monospace only when identifier comparison benefits. Never make 10px or 11px text the density strategy.

Use the token scale: 2, 4, 6, 8, 12, 16, 24px.

- MICRO: 2–6px for icon/label and badge internals.
- COMPONENT: 6–8px inside controls, table cells, toolbar groups.
- GROUP: 12px between related fields or metadata rows.
- SECTION: 16px between logical sections; 24px only between major regions.
- PAGE: 24px around major page regions, reduced where the workspace must prioritize visible records.

Whitespace exists to express grouping, hierarchy, or recovery space. Remove decorative emptiness before reducing readable text or hit targets. Touch overrides may enlarge spacing and targets without changing the information priority model.
