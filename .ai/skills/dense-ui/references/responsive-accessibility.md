# Responsive and accessibility guidance

Dense desktop is the default. Mobile is adaptive, not shrunk desktop. Preserve essential identity, status, task controls, and recovery paths. Hide tertiary columns first; pop-in/stack secondary data with labels; use horizontal scroll only when comparison remains meaningful; collapse toolbar actions into labelled menus; adapt tabs into a scrollable tablist or explicit section navigation.

Accessibility overrides density. Use semantic HTML, labelled controls, logical headings, visible focus, sufficient contrast, keyboard operation, predictable focus restoration, screen-reader announcements for async status, error identification, zoom/reflow at 200%, and reduced motion where relevant. Keep interactive targets usable on touch even when visual controls are compact. Never use color as the only status or validation signal.

Touch/scanner is an adaptation: enlarge physical hit targets, scan areas, quantity controls, and feedback while keeping grouping, information priority, and workflow short.
