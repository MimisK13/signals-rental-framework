# Projects

Groups related opportunities for commercial and resource planning without replacing each opportunity's Store, dates, availability, or financial ownership.

## Owns

- Project lifecycle and member metadata.
- Opportunity attachment, movement, and detachment.
- Project API and native presentation.

## Boundary

Opportunities, Crew scheduling, Documents, Members, and Stores remain collaborating domains.

## Direction

Projects is intended to evolve into the application's central coordination context, bringing related commercial, planning, resource, operational, and financial workflows together. The primary commercial flow is Project-first, with multiple Quotations per Project; accepting a standalone Quotation creates and links its Project.
