# Quotations

Owns independent commercial quotations that may belong to an existing Project or remain standalone until acceptance creates and links a Project.

## Owns

- Quotation, version, and item commercial state.
- Replayable version creation, activation, sending, decline, and acceptance events.
- Immutable accepted baselines and idempotent acceptance-to-Project.
- Replayable item trees with rate/tax pricing snapshots and editor read projections.
- Project-first and standalone creation paths.
- Native quotation list, creation, lifecycle, and local-first editor presentation.
- Flat/proportional deal pricing, substitution, combination expansion, and read-only availability previews.
- Canonical REST API, document merge data, and quotation lifecycle notification/webhook definitions.

## Boundary

Projects coordinate delivery; Rates, tax, products, Documents, availability, and notifications remain collaborating domains.
