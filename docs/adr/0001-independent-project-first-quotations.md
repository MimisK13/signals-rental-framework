# Independent Project-first Quotations

Quotations will be an independent aggregate rather than an Opportunity lifecycle state. The primary flow is Project → Quotations, while a standalone Quotation is also allowed and creates and links exactly one Project when accepted. New Quotations use new canonical Verbs streams; existing Opportunity event classes remain immutable replay contracts and migration-source history, while the experimental editor will be ported to canonical Quotation actions without a permanent Opportunity adapter.
