# Tailwind example

Use semantic component classes or shared token variables rather than repeating arbitrary values. Example composition: `flex min-h-[var(--dense-control-height)] items-center gap-2`; table cells use `px-[var(--dense-cell-padding-x)] py-[var(--dense-cell-padding-y)]`; numeric cells use `text-right tabular-nums`; focus uses the project’s accessible ring utility. Tailwind is optional; do not make the skill depend on a component library.
